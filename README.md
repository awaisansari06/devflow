## ⚡ Overview

**DevFlow** redefines the coding experience by integrating **Google's Gemini 2.0 Flash** directly into a secure, sandboxed environment. Think of it as your pair programmer that doesn't just suggest code—it runs it, tests it, and iterates on it in real-time.

> "It's not just an editor; it's an intelligent coding companion."

## 🚀 Getting Started

<details>
<summary><b>Click to expand installation details</b></summary>

### 1. Clone & Install
```bash
git clone https://github.com/yourusername/devflow.git
cd devflow
npm install
```

### 2. Configure Environment
Create a `.env` file with your keys:
```bash
cp .env.example .env
```

### 3. Run the App
```bash
npm run dev
```
Visit `http://localhost:3000` to start building!
</details>
